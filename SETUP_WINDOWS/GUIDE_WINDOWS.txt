                    🖥️ INSTALLATION PC SERVEUR (PC 1)
═══════════════════════════════════════════════════════════════════════════════

┌─────────────────────────────────────────────────────────────────────────────┐
│  ÉTAPE 1: INSTALLER MARIADB                                                 │
└─────────────────────────────────────────────────────────────────────────────┘

  1. Télécharger MariaDB:
     https://mariadb.org/download/?t=mariadb&p=mariadb&r=11.8.1
     
  2. Lancer l'installateur
  
  3. IMPORTANT: Noter le mot de passe ROOT que vous choisissez!
  
  4. Cocher "Use UTF8 as default server's character set"
  
  5. Terminer l'installation

┌─────────────────────────────────────────────────────────────────────────────┐
│  ÉTAPE 2: CONFIGURER LA BASE DE DONNÉES                                     │
└─────────────────────────────────────────────────────────────────────────────┘

  1. Ouvrir HeidiSQL (installé avec MariaDB)
     → Menu Démarrer → HeidiSQL
     
  2. Créer une nouvelle connexion:
     - Cliquer "Nouveau"
     - Nom: MariaDB Local
     - Hôte: 127.0.0.1
     - Utilisateur: root
     - Mot de passe: [votre mot de passe root]
     - Cliquer "Ouvrir"
     
  3. Ouvrir le fichier SCRIPT_SQL_COMPLET.sql:
     - Menu Fichier → Ouvrir
     - Sélectionner SCRIPT_SQL_COMPLET.sql
     
  4. Exécuter le script:
     - Cliquer sur ▶️ (ou appuyer F9)
     - Attendre que toutes les requêtes s'exécutent
     
  5. Vérifier:
     - Dans le panneau gauche, vous devez voir "physiocare"
     - Cliquer dessus pour voir toutes les tables

┌─────────────────────────────────────────────────────────────────────────────┐
│  ÉTAPE 3: AUTORISER L'ACCÈS RÉSEAU                                          │
└─────────────────────────────────────────────────────────────────────────────┘

  A) Modifier la configuration MariaDB:
  
     1. Ouvrir l'explorateur de fichiers
     2. Aller dans: C:\Program Files\MariaDB 11.8\data\
     3. Ouvrir my.ini avec Notepad (clic droit → Modifier)
     4. Chercher la section [mysqld]
     5. Ajouter cette ligne:
     
        bind-address = 0.0.0.0
        
     6. Sauvegarder et fermer

  B) Redémarrer MariaDB:
  
     1. Appuyer Win + R
     2. Taper: services.msc
     3. Trouver "MariaDB" dans la liste
     4. Clic droit → Redémarrer

  C) Ouvrir le pare-feu:
  
     1. Appuyer Win + X → Windows PowerShell (Admin)
     2. Coller cette commande:
     
        New-NetFirewallRule -DisplayName "MariaDB" -Direction Inbound -LocalPort 3306 -Protocol TCP -Action Allow
        
     3. Appuyer Entrée

┌─────────────────────────────────────────────────────────────────────────────┐
│  ÉTAPE 4: INSTALLER NODE.JS                                                 │
└─────────────────────────────────────────────────────────────────────────────┘

  1. Télécharger Node.js LTS:
     https://nodejs.org/
     
  2. Lancer l'installateur
  
  3. Suivre les étapes (garder les options par défaut)
  
  4. Redémarrer l'ordinateur (recommandé)

┌─────────────────────────────────────────────────────────────────────────────┐
│  ÉTAPE 5: LANCER PHYSIOCARE                                                 │
└─────────────────────────────────────────────────────────────────────────────┘

  1. Double-cliquer sur INSTALLER_PHYSIOCARE.bat
     (dans ce dossier SETUP_WINDOWS)
     
  2. Attendre l'installation des dépendances
  
  3. L'application se lance automatiquement!

│  ÉTAPE 8: NOTER L'IP DU SERVEUR                                             │
└─────────────────────────────────────────────────────────────────────────────┘

  2. Taper: ipconfig

                         ❓ RÉSOLUTION DES PROBLÈMES
═══════════════════════════════════════════════════════════════════════════════

PROBLÈME: "Connexion refusée" depuis le PC Client
──────────────────────────────────────────────────
  ✓ Vérifier que les 2 PC sont sur le même réseau WiFi/Ethernet
  ✓ Vérifier que MariaDB est démarré sur le serveur (services.msc)
  ✓ Vérifier que le pare-feu autorise le port 3306
  ✓ Vérifier que bind-address = 0.0.0.0 est configuré
  ✓ Essayer de ping l'IP du serveur depuis le client

PROBLÈME: Erreur lors de la création de kiné
────────────────────────────────────────────
  ✓ Exécuter le SCRIPT_SQL_COMPLET.sql dans HeidiSQL
  ✓ Vérifier que la table kine_staff existe

PROBLÈME: Erreur lors des paiements/argent
──────────────────────────────────────────
  ✓ Exécuter le SCRIPT_SQL_COMPLET.sql dans HeidiSQL
  ✓ Vérifier que les tables payments et kine_sessions existent

PROBLÈME: "npm n'est pas reconnu"
─────────────────────────────────
  ✓ Redémarrer l'ordinateur après installation de Node.js
  ✓ Réinstaller Node.js
