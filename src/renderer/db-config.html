ℹ️ Mode réseau multi-postes

Pour le mode réseau, installez MariaDB sur le PC principal et connectez les autres PC à l'IP de ce serveur.

Le PC principal doit avoir une adresse IP fixe sur le réseau local (ex: 192.168.1.100).
