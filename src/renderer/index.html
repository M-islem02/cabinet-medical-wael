Le mode recommandé est hors-ligne: base locale + bundle chiffré + export transportable. Avec le même mot de passe, vous pouvez restaurer sur un autre PC à tout moment.

🛡️ Espace Administrateur

Vous êtes connecté avec le compte administrateur destiné aux installateurs. Ce profil n'est pas rattaché au cabinet et ne peut pas remplir les informations médicales.

  1. Activer la licence annuelle du cabinet via la carte « Informations de Licence ».
  2. Créer le compte médecin dans « Gestion des Utilisateurs » et lui communiquer ses identifiants.
  3. Se déconnecter pour laisser le médecin saisir les informations du cabinet et utiliser l'application.
  4. À l'expiration de la licence, reconnectez-vous avec l'admin pour réactiver l'année suivante.

Remarque : les formulaires ci-dessous restent verrouillés tant qu'un compte médecin n'est pas connecté.
