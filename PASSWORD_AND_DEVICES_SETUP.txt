MEDCARESO - PASSWORDS AND DEVICES
=================================

1. PASSWORDS
------------
All password fields now support:
- Voir
- Masquer

This applies to:
- Cloud API keys
- Telegram token
- SMS token
- Change my password
- New user password fields

2. CHANGE MY PASSWORD
---------------------
Path:
- Parametres
- Changer mon mot de passe

User flow:
- current password
- new password
- confirm password
- save

3. ADMIN / PRACTITIONER RESET
-----------------------------
Admins can reset other non-protected users without the old password.

In user management:
- click "Reinitialiser MDP"
- MedCareSO generates a temporary password
- give it privately to the user

Rules:
- super admin stays protected
- other admins stay protected
- practitioners can reset assistants

4. DEVICES SAVED IN SETTINGS
----------------------------
The settings page now remembers:
- standard printer
- thermal printer
- USB scanner

These choices are stored in the database and stay saved after closing the app.

5. SCANNER BEHAVIOR
-------------------
- if a preferred scanner is selected, MedCareSO uses it first
- if not, MedCareSO uses the first available scanner
- attached files can still be imported from PC/USB manually

6. THERMAL PRINTER USE
----------------------
- choose the thermal printer in settings
- appointment tickets stay in the compact thermal format
- the selected printer preference is kept for future sessions

7. RECOMMENDED CABINET SETUP
----------------------------
- one standard printer for A4 documents
- one thermal printer for RDV tickets
- one USB scanner for radios/analyses
- keep scanner and printer names saved in settings before daily use
